POS Backup Privacy Policy

POS Backup is a desktop point-of-sale application used by a single shop to manage its sales and inventory.

What the app accesses: With the user's permission, the app creates a folder named "POS Backups" in the user's own Google Drive and uploads backup copies of the shop's database to it. It uses only the "drive.file" permission, so it cannot see or change any other files in the user's Drive.

Data collection: The developer does not collect, receive, store, share or sell any user data. Backup files go directly from the shop's computer to the shop owner's own Google Drive.

Revoking access: The user can disconnect at any time from the app, or at myaccount.google.com/permissions.
